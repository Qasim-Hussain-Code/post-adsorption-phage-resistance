WHAT THE SCORE ADDS
  Not power. The four thresholds reuse the same observations, so no valid combination of them yields much beyond what the first threshold already provides, and the deeper thresholds have fewer events to work with.
  What it adds is a consistency check that the binary analysis cannot perform. The effect sizes are stable across thresholds for every system tested, which means the associations reported throughout this analysis are not artefacts of where the lysed and not-lysed boundary was drawn. Had a system acted only at the first threshold, or only at the deepest, the binary summary would have been misleading about it. None does.

LIMITS
  The four thresholds are nested, so the fits are not independent and the pooled estimate's interval would be far too narrow. It is reported as a summary of direction and magnitude only; the per-threshold estimates are the ones with honest intervals.
  Conditioning on a higher threshold conditions on a successful infection having happened, so an effect at threshold 4 mixes an effect on productivity with selection on which pairs reached that far. This is the same collider problem flagged for the lytic-pairs-only analysis in script 03.
